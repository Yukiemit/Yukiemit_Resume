WALBAUM FONT FILES GO HERE

Walbaum is a commercial typeface (Monotype), so it can't be bundled with this project.
If you have a web licence, export the files as WOFF2 and name them exactly:

  Walbaum-Regular.woff2
  Walbaum-Italic.woff2
  Walbaum-Bold.woff2        (optional)

Restart / refresh and every heading switches to Walbaum automatically.
Until then the site uses Bodoni Moda (free, Google Fonts), the closest classicist serif.
